## The entry

> Monday, one star: 47 unread emails before coffee, a standup that should have been a message, and a meeting about the meeting. My weekend has filed a complaint.

A one-line, one-star review of a Monday: concrete details (47 unread emails, a standup that should have been an email, a meeting about the meeting), with the punchline landing on the last word — "My weekend has filed a complaint."

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

`main.py` (Python 3 stdlib only) validates the entry against the gate — UTF-8, 1–200 characters, single line, not only whitespace — writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), then reads the file back and verifies the bytes match exactly.
